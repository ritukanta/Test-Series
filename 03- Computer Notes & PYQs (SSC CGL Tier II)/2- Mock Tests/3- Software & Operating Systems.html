1. Software

85 Questions | 85 Minutes

Please read the instructions carefully before starting the examination:

  1. The clock is set at the server. The countdown timer in the top right corner of screen will display the remaining time available for you to complete the examination (85 minutes for 85 questions). When the timer reaches zero, the examination will end and submit by itself.
  2. One Multiple Choice Question (MCQ) is displayed on the screen at a time with four options. Options are randomized on each fresh attempt while maintaining question order.
  3. Selecting an option does not automatically advance to the next question or reveal the answer during the test. Click Next or Mark for Review & Next to save your response and move forward.
  4. You can use the Clear button to deselect your chosen response for the current question at any time before submission.
  5. The Question Palette displayed on the right side of the screen (on desktop/tablet screens) shows the status of each question using the following symbols:
Question Palette Symbols:
1 You have not visited the question yet.
2 You have visited but not answered the question.
3 You have answered the question.
4 Marked for review (not answered).
5 Answered and Marked for Review.

Note: Clicking Start Mock Test will automatically enter Fullscreen mode and start the countdown timer. Upon submission, detailed solutions and explanations will be shown exclusively for incorrect and un-attempted questions.
