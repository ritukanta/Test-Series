1. Software & Types

Comprehensive Notes & Question Bank (Includes Windows OS & Explorer)

Core Concepts & Definitions

  • Software: A collection of instructions, data, or programs; these are intangible components used to operate computers and execute specific tasks.
  • Mobile Software: Referred to as Applications (Apps).
  • Source Code: The human-readable code required to create software.
  • Module: The smallest functional unit of software.
  • Software Composition: A collection of modules.

File Extensions

Windows

  • .exe, .com, .msi (Microsoft Installer)

macOS

  • .app (App Bundle), .dmg (Disk Image), .pkg (Package)

Linux

  • Debian: .deb, .sh
  • RedHat: .rpm, .sh

Mobile OS

  • Android: .apk (Android Package Kit), .xapk
  • iOS: .ipa

Software Classification & Licensing

Source Code Types

  • Open Source: Free of cost, source code is available and editable.
    Examples: Android OS, Linux OS, Firefox, Chromium.
  • Closed Source: Proprietary code. Restricted by developer/manufacturer.
    Examples: MS Office, Tally, ERP (Enterprise Resource Planning), SAP (Systems, Applications, Products).

Distribution Models

  • Freeware: Proprietary software available for no cost (e.g., Media Players).
  • Shareware: Distributed for free but requires payment to unlock premium features.
  • Trialware: Type of shareware that expires after a specific time limit.
  • Nagware/Annoyware: Shareware that functions but persistently interrupts with pop-ups.

Important Terms

  • Executable: Collection of Object Code or Machine Code.
  • Patch: Repair of a bug available for free online.
  • Malware: Malicious Software (Virus, Worm, Adware, Trojan, etc.).
  • EULA: End User License Agreement (Contract between User and Publisher).

System vs. Application Software

System Software

Designed to operate the computer hardware and provide a platform for applications.

  • Utility Software: Analyzes, configures, optimizes, and maintains the computer. (e.g., Antivirus, Disk Defragmenter, Disk Cleaner, Compression tools like 7-Zip, WinRAR).
  • Operating System: Windows, macOS, Linux, Android, iOS.
  • Drivers: Software used to run specific hardware.
  • Firmware: Permanent software programmed into read-only memory (BIOS/UEFI, Traffic Lights, Embedded systems).

Application Software

Designed for specific tasks for the end-user.

  • Examples: MS Office, Web Browsers, Media Players (VLC), Accounting (Tally).
  • Horizontal Software: General purpose, anyone can use (e.g., MS Word).
  • Vertical Software: Niche/Industry-specific (e.g., Finacle for banking).

Programming & Translation

Translators

  • Compiler: Converts High-Level Language (HLL) to Machine Language (ML). Converts the entire source code to object code at once. Shows all errors at the end.
  • Interpreter: Converts HLL to ML line-by-line. Shows errors after every line.
  • Assembler: Converts Assembly Language into Machine Language.
  • Note: Java uses both Compiler and Interpreter.

3. Programming

Comprehensive Guide & Computer Science Facts

Programming Language Definition

It is a set of commands, instructions, and other syntax and semantics, used to create a software program.

Types of Languages

Low Level Language (LLL)

Difficult to understand. There are two types:

  • Machine Language: The only language understood by computers. Also referred to as Machine code, object code, or binary language (e.g., raw 0s and 1s).
  • Assembly Language: Grants direct manipulation of hardware registers for precise control. Assemblers translate human-readable mnemonics into executable binary code. (Examples: x86 Assembly, ARM Assembly, MIPS Assembly).

Medium Level Language (MLL)

Designed to improve the translated code before it is executed by the processor.

  • Examples: C, C++, Java

High Level Language (HLL)

Prioritizes abstraction, readability, and portability across different computers. Faster and Simpler.

  • Examples: Python, Java, C++, C#, JavaScript, Ruby, etc.

Generational Languages

  • 1st Gen: Machine Language (Binary code)
  • 2nd Gen: Assembly Language (Mnemonics)
  • 3rd Gen: C, C++, Java, FORTRAN, COBOL, PASCAL (Software Making)
  • 4th Gen: Perl, Python, Ruby, SQL, MatLab (Database Languages)
  • 5th Gen: Mercury, Ops5, LISP and Prolog (AI / Robots / Machine)

Object-Oriented Programming (OOP)

Examples: Simula, Smalltalk, Java, JavaScript, Python, C++, Visual Basic .NET, Ruby, Scala, PHP.

Class & Object

A class is a blue-print for creating objects (a particular data structure), providing member variables, attributes, and implementations of Member Functions or Methods.

Encapsulation

The principle in OOP that binds data and methods that manipulate that data into a single unit, known as a class. (Diagram: Methods + Data -> Class)

Polymorphism

Where a single entity (method or object) takes multiple forms, allowing different classes.

Data Hiding

The principle of Encapsulation that helps to protect the Data.

Data Abstraction

The technique of hiding complex, internal implementation details of data while exposing essential features and behaviours to the user.

Inheritance

Mechanism by which one class is allowed to inherit the features of another class.

OOP History and Facts

  • First-ever High-Level Language: FORTRAN (Formula Translation); founded by John Backus.
  • First-ever OOP Language: SIMULA (Simulation Language), specifically Simula 67.
  • First-ever Purely Object-Oriented Language: Smalltalk.
  • Facebook Stack: Front-end (JavaScript, React, CSS, PHP), Chat System (Erlang), Backend (Python, GO, C#).
  • Internet-based languages: JavaScript, HTML.
  • Scientific Languages: Python, MatLab, R, FORTRAN.
  • Animation-based Language: JavaScript.
  • Microsoft's OOP Language: Visual Basic (VB).

C Programming

  • Designed by Dennis Ritchie at Bell Labs in 1972.
  • A compiled language.
  • First OS created with C: Unix.
  • Structured programming.
  • Also called ANSI C.
  • Used in building Chromium browser, MySQL database.
  • It is case-sensitive.
  • 32 keywords.
  • Widely used in Embedded Systems / IoT Applications.
  • A High-Level Language. Platform independent.
