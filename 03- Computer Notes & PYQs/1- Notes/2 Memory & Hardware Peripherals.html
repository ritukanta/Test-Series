Chapter 1: Memory

System Memory Archive | Classified and structured.

Memory Classification

Primary Memory (Internal)

  • RAM
  • ROM
  • Cache
  • Register

Secondary Memory (External)

  • Hard Disk
  • CD / Ray Disc Drive

RAM (Random Access Memory)

  • Volatile or Temporary Memory.
  • Founder: Robert Heath Dennard.
  • Capacity: Read + Write.
  • Speed units: Mega Hertz (MHz) or Millions of cycles per second.

SRAM (Static RAM)

  • Used to create: Cache memory.
  • Fastest RAM.
  • Made up of: Transistors.
  • Does not need to be refreshed constantly.

DRAM (Dynamic RAM)

  • Needs refresh.
  • Used in Laptops, Mobiles, PCs.
  • Made up of Capacitors.
  • Types: SDRAM (Synchronous), DDR (Double Data Rate) 1-5.

ROM (Read-Only Memory)

  • Ability: Only Reads. Permanent Memory.
  • Helps in Boot Up. Non-volatile in nature.
  • Used to store: BIOS Software (Basic Input Output System).
  • Instructions stored in ROM are known as Firmware (Hardware + Software).

ROM Types:

  • PROM (Programmable ROM): Editing is not possible once programmed.
  • EPROM (Erasable Programmable ROM): Editing is possible by UV Rays (by Manufacturer).
  • EEPROM (Electrically Erasable Programmable ROM): Editing is possible by electrical signals (e.g., Flash memory, Pen Drive, Memory Card, Solid State Drive/SSD).

Order of Fastest Memory

Register > Cache > RAM > ROM

Cache Memory

  • Second fastest memory. Temporary and volatile.
  • Part of Main Memory. Located between CPU and RAM.
  • Holds frequently used instructions and data.
  • Hit: Data/Word found in Cache.
  • Loss: Data/Word not found in Cache.
  • Performance measured in: Hit Ratio.
  • Levels: L1 (Registers, 64KB-128KB per core), L2 (Cache, 512KB-2MB per core), L3 (Primary memory, 16MB-96MB shared).
  • LRU (Least Recently Used): A common caching strategy (Replacement in Cache). When Cache is full, LRU technique makes room for new elements by discarding the 'least recently used data' first.

Register

  • Fastest memory. Resides inside CPU.
  • Collection of Flip Flops is called a Register.
  • Holds data: 32-bit/64-bit. CPU speed is determined by the number of bits of registers.
  • Functions: Fetch, Decode, Execute.

Types of Registers (7):

  1. Accumulator Register: Stores data for ALU.
  2. Address Register: Stores address; not a visible register.
  3. Data / Buffer Register: Stores data.
  4. Instruction Register: Holds last instruction.
  5. Program Counter: Points to next instruction.
  6. Memory Address Register (MAR) / Others (Included generally in the 7 categories).

Virtual & Buffer Memory

Virtual Memory

  • Illusion of having larger RAM.
  • Takes space from: Secondary Memory (e.g., Hard Disk).
  • Swap in and Swap out operations are used.
  • Works on the concept of page replacement.
  • Implemented via Demand Paging.

Buffer Memory

  • Temporary storage, usually in RAM.
  • Purpose: To hold data right before it is used.
  • e.g., When downloading an audio/video file, it loads the first 20% into buffer memory and then begins to play.

Memory Units & Conversions

Ascending Order: Bit → Nibble → Byte → KB → MB → GB → TB → PB → EB → ZB → YB → BB (Bronto Byte) → GB (Geop Byte)
  • 1 Bit = Binary digit (0 or 1)
  • 4 Bits = 1 Nibble
  • 8 Bits = 1 Byte
  • 2 Nibbles = 1 Byte
  • 1024 Bytes = 1 KB
  • 1024 KB = 1 MB
  • 1024 MB = 1 GB
  • 1024 GB = 1 TB

Chapter 2: Backup Devices & Protocols

Wayne Enterprises System Diagnostics Notes. 100% Fact-Checked.

This section contains system diagnostics and factual records categorized by Hardware, Protocols, Interfaces, and Cloud Infrastructure, structured in a highly accessible Q&A format with rich contextual analysis.

Ports & Interfaces

  • Which among the following ports is also known as Line Printer Port?
    Parallel — Also known as the IEEE 1284 standard. It utilized a 25-pin DB-25 connector and was the primary method for connecting printers to PCs before the ubiquity of USB.
  • Which port transmits one bit of a byte at a time as a single stream of bits (meant for slow data over long distances)?
    Serial — Typically utilizing the RS-232 standard (9-pin DE-9 or 25-pin DB-25). Because data is sent sequentially, it avoids crosstalk issues that plague parallel ports over long cables.
  • Which among the following ports is also called as mouse port?
    PS/2 — Introduced by IBM in 1987. A 6-pin mini-DIN connector. Historically color-coded: green for mice and purple for keyboards. Modern gaming boards sometimes keep it for true hardware interrupts (lower latency).
  • How many pins does the LPP (Line Printer Port) model have?
    25 — The LPT natively utilizes 25 pins to transmit 8 bits of data simultaneously along with grounding and control signals.
  • A serial port has which number of pins versions?
    9-pin and 25-pin — Legacy serial ports came in two primary formats: DE-9 (9-pin) for standard desktop use, and DB-25 (25-pin) for specialized hardware. Modern boards have made this obsolete in favor of USB.
  • Which of the following is the port number 80 on a computer?
    HTTP — Port 80 is designated for unencrypted Hypertext Transfer Protocol. Modern secure web traffic uses HTTPS over Port 443.
  • Which interface is most commonly used for connecting external backup hard drives?
    USB — Universal Serial Bus is the industry standard due to plug-and-play capability and high throughput.
  • Which port is commonly used for network backups in NAS systems?
    RJ-45 — Standard connector for Ethernet cables. NAS relies on Ethernet to integrate with LANs.
  • The FireWire (IEEE-1394) port is mainly used for:
    Scanners and External Drives — Historically favored by Apple for high sustained transfer rates and daisy-chaining (video editing).
  • Which of these is a port for analog video transmission?
    VGA — Video Graphics Array is a 15-pin connector that transmits analog RGB video signals. Degrades over long distances and lacks audio. Also commonly used for connecting older projectors.
  • Which of these ports supports both audio and video in a single cable?
    HDMI — High-Definition Multimedia Interface transmits uncompressed digital video and compressed/uncompressed digital audio simultaneously.
  • The USB Type-C connector can support which of the following features?
    Data + Power + Video — Through 'Alternate Modes', a single 24-pin Type-C cable can carry 40Gbps data, 240W power (USB-PD), and DisplayPort/HDMI video.
  • The maximum theoretical speed of USB 3.0 is:
    5 Gbps — Introduced SuperSpeed transfer, outperforming USB 2.0's 480 Mbps.
  • The eSATA port is used for:
    External Storage Devices — Provided native internal SATA speeds to external drives before USB 3.0 became fast enough to render it obsolete.

Storage Hardware & Diagnostics

  • Which backup device provides a convenient way to create system images and complete backups, but requires a lengthy restoration process?
    Tape drive — Magnetic tape relies on sequential access (physically winding the ribbon). Slow restoration, but excellent, cost-effective massive long-term archival.
  • Which of the following is a principle of operation for magnetic disks?
    Direct access — Magnetic hard drives utilize read/write heads on mechanical arms that can move directly to specific tracks and sectors on spinning platters (random/direct access).
  • Which of the following has the highest data transfer rate among backup devices?
    SSD — Solid State Drives use NAND flash memory. No mechanical moving parts; modern PCIe/NVMe SSDs achieve transfer rates exceeding 7,000 MB/s.
  • Which of the following uses laser light to read data?
    Optical Disc (CD, DVD, Blu-ray) — CDs (Infrared), DVDs (Red), Blu-ray (Blue-violet) use focused lasers to read microscopic pits and lands etched into a polycarbonate layer. Immune to electromagnetic damage (EMPs). Limitation: Small capacity and physical degradation (disc rot).
  • Which backup device is best suited for enterprise data centers with high reliability requirements?
    Tape Library — Automated tape libraries utilize robotic arms to manage magnetic tape cartridges (LTO). Offers Petabytes of storage at low cost.
  • Which device provides network-based centralized backup?
    NAS (Network Attached Storage) — Operates as independent file servers on the network, allowing simultaneous multi-user accessibility across LAN/WAN protocols (SMB/NFS).
  • Which statement about Optical Jukebox systems is true?
    Uses robotic arms to load optical discs automatically — Similar to a tape library, physically manipulates hundreds/thousands of high-capacity optical discs.

Backup Protocols & Cloud Infrastructure

  • Which is process of creating a duplicate set of program or data files for safekeeping?
    Backing up — Fundamental IT disaster recovery principle. Ensures a secondary operational copy exists against corruption/ransomware.
  • Which of the following backup methods stores only the data that has changed since the last FULL backup?
    Differential Backup — Grows in size each day. Allows for faster restoration than incremental backups (requires only the Full Backup + Latest Differential).
  • Which statement about Incremental Backup is correct?
    Copies all files changed since the LAST incremental backup. — Takes less time daily, but requires the Full backup plus *every* sequential Incremental backup in exact order to restore.
  • The term RAID-5 in backup refers to:
    Striping with distributed parity — Requires a minimum of 3 drives. Survives the failure of one drive without data loss.
  • In RAID systems, data is divided into blocks and distributed across drives. This is called:
    Striping (RAID 0) — Increases read/write performance by utilizing multiple controllers, but offers zero redundancy if a drive fails.
  • Which statement about RAID-1 is correct?
    Provides mirroring — Writes identical data to at least 2 drives simultaneously. Continues seamlessly if one fails.
  • Which backup system performs real-time synchronization?
    Continuous Data Protection (CDP) — Captures every version saved, allowing restoration to any specific point in time without scheduling backup windows.
  • What is Data Deduplication in backup systems?
    Removal of duplicate data blocks — Replaces identical files/blocks with tiny reference pointers, saving vast amounts of storage.
  • What best distinguishes Archiving from Backup?
    Archiving removes inactive data for long-term storage — Backup is a copy of active data. Archive moves stagnant data off primary storage for compliance and space-saving.
  • Amazon Web Services 'Glacier' refers to:
    Cold Data Archival Storage — Extremely low storage costs for long-term, rarely accessed data, but retrieval takes time.
  • Which of the following protocols is used for secure file transfer in cloud backup?
    SFTP — SSH File Transfer Protocol encrypts both commands and data.
  • How do cloud backup systems ensure data availability?
    Geo-replication across data centers — Replicates data across multiple physical zones/continents to ensure survival against localized natural disasters.

Chapter 3: Printers

Bat-Computer Intelligence | Comprehensive Printer Repository.

Historical Origin & Connectivity

  • Founder: Johannes Gutenberg (1440).
  • Primary Function: Converts soft copy (digital) into hard copy (physical).
  • Arrival in India: First introduced in Goa via Francis Xavier.
  • Electronic Milestone: The EP-101 by Epson (Japan) was the first electronic printer.
  • Connectivity: Connects to PC via Parallel Port (historically) or USB Port (modern). Parallel port cannot connect monitors.
  • Measurement: Both Resolution and Output Quality are measured in DPI (Dots Per Inch).
  • Advanced Form: Plotter (used for big charts/maps) or Laser printer.

Quick Printer Facts (General)

  • Head & paper forced together? Impact printer
  • First impact printer? Dot matrix printer
  • First press in India? Goa
  • Resolution & Quality measured in? DPI
  • Parallel port used in? Printer

I. Impact Printers

Direct physical contact between print head and paper.

Dot Matrix Printer

  • Invented: Robert Howard, IBM (1957).
  • Uses fixed number of pins/wires to strike ink ribbon.
  • Speed: CPS (Characters Per Second).
  • Main Advantage: Creating carbon copies.
  • Less expensive than Laser.
  • Example of a Character Printer.

Daisy Wheel Printer

  • Invented: Andrew Gabor (1970).
  • Known as "Golf Ball Printer".
  • Mechanism: Like a typewriter; uses a wheel.
  • Constraint: Slow, noisy, cannot print graphics.
  • NOT silent in operation.

Chain & Drum Printers

  • Known as Line Printers.
  • Chain printer: Chain of characters. Impact & Monochrome.
  • Drum printer: Both Character & Line attributes depending on design.
  • Speed: LPM (Lines Per Minute).

II. Non-Impact Printers

Uses heat, laser, or spray; no direct physical strike.

Thermal Printer

  • Invented: Jack Kilby (1965).
  • Uses heat + special Thermo-chromic paper (Bisphenol paper blackens on heat).
  • "Inkless Printer", used in ATMs, POS devices, Banking, Grocery, Fax Machines.

Inkjet Printer

  • Developed by: HP (1976).
  • Uses Ink Cartridges.
  • Mechanism: Spray-painting via nozzles (droplets).
  • Best for: Photos and Graphics.

Laser Printer

  • Invented: Gary Starkweather, Xerox (1969).
  • Uses Photocopy technology + Toner (Dry Ink Powder).
  • Mechanism: Electrostatically charged drum (OPC: Organic Photo Conductor).
  • Speed: Fastest (100+ PPM).
  • Best for: Business, Desktop Publishing.

  • Change toner when? Empty Toner
  • Solenoid purpose? Paper feed
  • Both sides printing mechanism? Duplexer
  • Network printer port? Ethernet
  • IP Assignment protocol? DHCP
  • ECU? Engine Control Unit
  • What is NOT used in a Laser printer? Print Head (uses laser/drum instead)
  • Best for big charts/maps? Plotters
  • What bonds toner permanently to paper? Fuser Assembly

Chapter 4: Computer Ports & Connectors

Front and Back Panel CPU Uses & Functions.

Introduction to Ports & Connectors

  • Definition: A physical docking point acting as an interface between the computer and other computers or peripheral devices.
  • Motherboard Connection: Integrated into the motherboard (Back Panel) or connected via internal cables (Front Panel).
  • Connectors (Male vs Female): Connectors are at the ends of cables. Male connectors have exposed pins; female ports have corresponding holes (receptacles).
  • Function: Transmit electronic signals, data, and power between the CPU and peripherals.

Front Panel Ports

  • Power & Reset Buttons: Power turns PC on/off. Reset performs hard reset without cutting power.
  • Front USB Ports: Convenient access (typically USB 2.0 Black, USB 3.0/3.1 Blue). Connected via internal headers.
  • Front Audio Ports: 3.5mm analog jacks. Microphone (Pink/Red) for input, Headphone/Speaker (Green) for output. Internally connects to AC'97 or HD Audio header.
  • Optical Drives & Media Cards: Legacy CD/DVD drives, SD Card readers (SD, MicroSD, CF).

Back Panel - Legacy Ports

  • PS/2 Port (Personal System/2): 6-pin Mini-DIN. Purple = Keyboard, Green = Mouse. Mostly replaced by USB.
  • Serial Port (COM Port): Sends data serially (1 bit at a time). Usually 9-pin (DE-9) or 25-pin (DB-25) Male. Uses RS-232 standard (Modems, automation).
  • Parallel Port (LPT): Line Printer Terminal. Sends multiple bits simultaneously (8 bits/1 byte at a time). 25-pin (DB-25) Female. Often Pink or Magenta (Printers, Zip drives).

Video & Display Ports

Port Name Type / Pins Signal Detailed Functions & Uses
VGA (Video Graphics Array) 15-pin (DE-15, 3 rows) Analog Video ONLY Classic blue port. Connects older CRT, LCDs, projectors. Susceptible to interference. No audio.
DVI (Digital Visual Interface) Up to 29-pins (White) Analog / Digital Replaced VGA for LCDs. Variants: DVI-A (Analog), DVI-D (Digital), DVI-I (Integrated). No native audio.
HDMI (High-Def Multimedia Interface) 19-pin (Type A) Digital Video + Audio Universal standard for modern displays/TVs. Carries uncompressed HD/4K video + digital audio in one cable.
DisplayPort (DP) 20-pin (Asymmetric) Digital Video + Audio High-end graphic interface. Preferred in PC gaming (144Hz+) and multi-monitor daisy-chaining. Carries USB data too.

USB (Universal Serial Bus)

Industry standard for digital data and power. Replaced serial, parallel, and PS/2. Types include Type-A (standard), Type-B (square, printers), Mini/Micro (phones), and Type-C (modern, reversible).

Network & High-Speed Ports

  • Ethernet / LAN Port (RJ-45): 8 pins. Connects PC to Local Area Network (LAN) or modem. Speeds: 10 Mbps to 10 Gbps. Has LED indicators (Link & Activity).
  • FireWire (IEEE 1394): Apple's legacy high-speed bus (400-800 Mbps). Used for camcorders/audio. Replaced by USB 3.
  • Thunderbolt: Intel/Apple tech combining PCIe (data) and DisplayPort (video). TB3/TB4 use USB-C shape, providing massive speeds (up to 40 Gbps) and power.

Internal Connectors & Cables

Power Connectors

  • 20/24-pin ATX Power: Connects SMPS to motherboard for main power.
  • 4/8-pin CPU Power: Supplies dedicated 12V power directly to CPU.
  • Molex Connectors: Older 4-pin peripheral power for IDE drives and case fans.

Data Connectors

  • SATA (Serial ATA): L-shaped 7-pin connector for modern HDD and SSD. Faster than IDE.
  • IDE / PATA: Legacy 40-pin ribbon cable for older hard drives and CD/DVD ROMs.
  • M.2 Connectors: Flat internal slot directly on motherboard for ultra-fast NVMe SSDs and Wi-Fi cards.
