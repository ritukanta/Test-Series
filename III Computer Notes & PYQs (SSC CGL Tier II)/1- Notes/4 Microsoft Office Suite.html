5. Essential Notes & Processes

  • 1. Page Setup & Formatting: Open the Page Layout tab to configure your document canvas. Set your Margins, Orientation (Portrait or Landscape), and Size (Standard is A4 or Letter). Use the Home tab for text adjustments like Font Face, Size, Bold, Italic, and Underline.
  • 2. Generating Dummy Text: Use formulas to quickly populate the document with random text for testing layouts.
    • Generate standard random text: Type =rand() and press Enter immediately after the closing parenthesis.
    • Generate specific amounts: Type =rand(3,5) to generate 3 paragraphs containing 5 lines each.
  • 3. The Format Painter: Copies the formatting of specific text and applies it to other areas. Highlight source text, click Format Painter, then highlight target text. 4. Formula Tab & Functions Overview

  • Switch Theme Shortcut: Alt + M
  • Formula Tab Groups: Insert Function, AutoSum, Function Library, Defined Names, Formula Auditing, Calculation.
  • Rule: All Formulas MUST start with an = (Equal to) sign.
  • Order of Operations (PEMDAS): Excel calculates in order: 1. Parentheses, 2. Exponents (^), 3. Multiplication (*) & Division (/), 4. Addition (+) & Subtraction (-). Rule for consecutive operators of same precedence (e.g. multiple divisions): Excel calculates Left to Right (e.g. 8/4/2 -> (8/4)/2 = 1).

Function Categories

  • Logical Functions: AND, FALSE, IF, IFERROR, IFNA, IFS, NOT, OR, SWITCH, TRUE, XOR.
    • AND: TRUE if all conditions are TRUE. (e.g. 1=1, 2=2 -> TRUE, 1=2, 2=3 -> FALSE).
    • IF: Checks condition. Returns one value if TRUE, another if FALSE. (e.g. IF(A1=25, "Pass", "Fail")).
    • NOT: Reverses logical value. NOT(TRUE) -> FALSE.
    • OR: TRUE if any condition is TRUE. FALSE only if all are FALSE.
  • Text Functions:
    • CONCATENATE / CONCAT: Joins strings. e.g. CONCATENATE("Parmar", " ", "Academy"). Enclose in double quotes.
    • LOWER / UPPER / PROPER: Lowercase, Uppercase, Capitalizes first letter of each word.
    • TRIM: Removes extra spaces leaving only single spaces between words.
    • LEN: Total characters in string (includes spaces).
    • SUBSTITUTE vs REPLACE: SUBSTITUTE replaces specific text. REPLACE replaces text based on position.
    • LEFT / RIGHT / MID: Returns characters from start/end/middle.
    • FIND (Case Sensitive) / SEARCH (Not Case Sensitive): Finds position of text.
    • EXACT: Checks if identical (Case Sensitive).
    • DOLLAR: Converts number to text using currency format.
  • Date & Time Functions: TODAY() (Current date), NOW() (Current date/time), DATE(y,m,d), DAY(), MONTH(), YEAR(), HOUR/MINUTE/SECOND(), DATEDIF (diff between dates).
  • Lookup & Reference Functions:
    • MATCH: Returns relative position. Types: 1 (Less than - Ascending array), 0 (Exact match), -1 (Greater than - Descending array).
    • VLOOKUP (Vertical - searches first column, moves across row), HLOOKUP (Horizontal - searches first row, moves down column).
    • ADDRESS, COLUMN/ROW, TRANSPOSE (Converts vertical to horizontal).
  • Math & Trig Functions:
    • ABS (Absolute value), SQRT, FACT (Factorial, 0!=1), PRODUCT, SUMSQ, GCD/LCM, MOD (Remainder - result sign matches divisor sign), POWER.
    • Rounding: ROUND (to specified digits), ROUNDUP, ROUNDDOWN, INT (Rounds down to nearest integer), TRUNC (Removes fractional part without rounding).
    • CEILING (Rounds up to multiple of significance), FLOOR (Rounds down to multiple).
  • Counting Functions: COUNT (Counts cells with numbers), COUNTA (Counts non-empty cells), COUNTBLANK (Counts empty cells).

5. Cursors & Errors Indications

Indication Marks (Cursors)

  • Black Arrow: Selects entire row/column.
  • Double-headed Arrow: Adjusts row height/column width.
  • Black Cross (Fill Handle): Copies formulas/fills series.
  • Four-headed Arrow: Moves selected cells.
  • White Plus: Selection cursor.
  • Red Triangle: Indicates a Comment.
  • Green Triangle: Indicates a potential Error.

Types of Errors

  • #DIV/0!: Division by zero.
  • #VALUE!: Wrong type of argument/operand.
  • #NAME?: Invalid text/function name.
  • #REF!: Invalid cell reference (deleted cells).
  • #NUM!: Invalid numeric values.
  • #N/A: Value not available (common in Lookup).
  • #NULL!: Incorrect range operator.
  • ####: Column is too narrow to display data.

Chapter 4: Microsoft Access

Target: OSSC CGL, OSAP CONSTABLE, RI ARI AMIN - RDBMS Concepts, Objects, Data Types and MCQs

1. Introduction to MS Access & Specs

  • What is MS Access? Microsoft Access is a widely used Relational Database Management System (RDBMS) developed by Microsoft. It is a part of the Microsoft Office Suite.
  • Combines the relational Microsoft Jet Database Engine with a graphical user interface and software-development tools.
  • Unlike MS Excel (financial/statistical data spreadsheet), MS Access handles large amounts of data, linking multiple tables through relationships.

Key Terminology

  • Database: An organized collection of structured information or data.
  • Record (Row): A complete set of information in a table (also called a Tuple).
  • Field (Column): A specific piece of information within a record (also called an Attribute).

Database Specifications & File Extensions

  • File Extensions:
    • .mdb: Default extension for MS Access versions prior to 2007 (e.g., 2000, 2003). Stands for Microsoft Database.
    • .accdb: Default extension for MS Access 2007 and newer. Stands for Access Database.
  • Size Limits: Maximum Database Size is 2 Gigabytes (2GB). (Absolute correct max limit).
  • Object Limits: Maximum 32,768 objects in a single database.
  • Name Limit: Max length of object name is 64 characters.

2. Core Objects, Data Types & Keys

Four Core Objects of MS Access

  • A. Tables: Foundational object storing all raw data arranged in rows and columns. Other objects rely on this data. Can establish Relationships (One-to-One, One-to-Many, Many-to-Many).
  • B. Queries: Tool used to retrieve or manipulate specific data based on conditions. Select Query retrieves/displays data. Action Queries perform actions (Append, Update, Delete in bulk).
  • C. Forms: User Interface (UI) for database entry, editing, and viewing. Prevents direct table interaction reducing corruption. Can contain buttons, text boxes, drop-downs.
  • D. Reports: Summarize, format, and print data. Read-only. Ideal for invoices, summaries, labels. Usually based on Queries.

Database Keys & Views

  • Primary Key (PK): Field (or combination) uniquely identifying each record. Cannot contain duplicates or be left blank (NULL). Example: Roll Number, Employee ID.
  • Foreign Key (FK): Field in one table uniquely identifying a row of another table. Used to establish relationship.
  • Datasheet View: Used to view, enter, and edit actual data. Looks like an Excel spreadsheet.
  • Design View: Used to create or modify structure (Field Names, Data Types, PK). No raw data entered here.
