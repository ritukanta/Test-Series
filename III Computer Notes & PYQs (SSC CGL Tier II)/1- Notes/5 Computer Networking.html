Networking Model History

1. TCP/IP Model

  • Full Form: Transmission Control Protocol / Internet Protocol
  • Developed in 1970's by US Department of Defence (DOD).
  • Adopted as the protocol standard for ARPANET in 1983.
  • Developers: Vint Cerf and Bob Kahn.

2. OSI Model

  • Full Form: Open Systems Interconnection Model
  • Introduced in 1984.
  • Developer: ISO (International Organization for Standardization) in 1984.
  • Nature: It is a Reference Model or Conceptual model. It is not practically implemented.
  • Purpose: Used by IT professionals to track the flow of data and understand how data transfers occur in networks.
  • Structure: Contains 7 layers. These layers follow a set of rules called Protocols.

The 7 Layers of OSI

7. Application Layer (Desktop Layer)

  • Network Virtual Terminal.
  • FTAM (File Transfer Access and Management).
  • Mail Services.
  • Directory Services.
  • Used by end-user software.

6. Presentation Layer

  • Translation (of data formats).
  • Encryption (for security).
  • Decryption.
  • Compression (to reduce data size).

5. Session Layer

  • Responsible for Session Management.
  • Handles Synchronization.
  • Acts as a Dialog Controller.

4. Transport Layer (Heart of OSI)

  • Known as the End-to-End Layer.
  • Establishes connection between source and destination.
  • Deals with Acknowledgement of data.
  • Provides Connection Oriented Service.
  • Provides Connection Less Service.

3. Network Layer

  • Routing and forwarding of packets.
  • Enables Internetworking.
  • Handles Logical Addressing (IP).

2. Data Link Layer

  • Handles MAC Addresses.
  • Ensures error-free transfer of data frames.
  • Manages Flow Control.
  • Manages Error control.
  • Sub-Layers: LLC (Logical Link Control) and MAC (Media Access Control).

1. Physical Layer

  • Maintains physical connections.
  • Handles Network Topology.
  • Defines Networking Modes.
  • Responsible for Bit synchronization.
  • Controls Bit Rate.

TCP/IP Network Model

  • TCP: Transmission Control Protocol and is Connection Oriented.
  • IP: Internet Protocol and is connectionless.
  • Developed in 1970's. Standardized in 1983.
  • Developed by US Department of Defence.
  • Developers: Vint Cerf and Bob Kahn.
  • Layers: 5 (Updated). Session Layer and Presentation Layer are not present.

Network Types

1. Local Area Network (LAN)

  • Private Network. Small Geographical Area.
  • Share Resources.
  • Data transfer Speed: 10 MBPS to 1 GBPS.
  • Devices: Hub/Switch.
  • High Security. Range: 100 metres to 2 KM.
  • Cable: Twisted pair Cable/Co-axial Cable.
  • IEEE developed specifications for LAN.
  • Types: Wired LAN: Cables (Ethernet 802.3). Wireless LAN: WiFi (802.11).

2. Metropolitan Area Network (MAN)

  • Covers a city.
  • Interconnects 2 LANs (LAN-MAN-LAN).
  • Cable: Optic Fibre.
  • Example: TV Networks cables.
  • Devices: Hub/Switch, Routers/Bridge.

3. Wide Area Network (WAN)

  • Is a Telecommunication Network.
  • Covers Countries (Large geographical Area).
  • Internet is largest in WAN.
  • Transmission Medium: Satellite.
  • Devices: Routers. Firewall is required.
  • e.g. Internet.

4. Personal Area Network (PAN)

  • Range: 10 metres.
  • Bluetooth enabled devices. Infrared-enable devices.
  • Hot spot.
  • Wireless keyboard and Mouse. Bluetooth enabled Headphones. Wireless printers, Remotes.

5. Storage Area Network (SAN)

  • e.g. Cloud computing.

6. Campus Area Network (CAN)

  • Also known as Corporate Area Network (CAN).
  • Group of interconnected LANs.
  • Range: 1 to 5 KM.

Internet vs. Intranet vs. Extranet

Internet

  • Public access.
  • Unrestricted and lowest level of security.

Intranet

  • Restricted strictly to one organization.
  • Employees only.

Extranet

  • Allows authorised outsiders to access a private network.

Transmission Modes & Media

Transmission Modes

  • Simplex: Unidirectional (One-way). Low performance. e.g. Keyboard, Monitor.
  • Half Duplex: Bidirectional (Two-way, but one at a time). Medium performance. e.g. Walkie-Talkie.
  • Full Duplex: Bidirectional (Two-way, simultaneous). High performance. e.g. Telephone/Mobile.

Transmission Media

Guided Media (Cables)
  • Twisted pair Cable: Shielded (STP - used in factory), Unshielded (UTP - LAN Connection).
  • Co-axial Cable: e.g. TV Cable.
  • Fibre optic cable: Set under Sea. Fastest. Broadband Connection.
Un-Guided Media (Waves)
  • Radio waves
  • Microwaves
  • Infrared waves

Network Topology

Topology refers to the geometric arrangement of a computer system. It describes the physical or logical layout of a network. It defines how different nodes (computer nodes, printers) are connected to each other and how they communicate.

Bus Topology

Multipoint Connection

  • All devices connect to a single central cable.
  • LAN Usage: Commonly used in Small LAN due to simple wiring.
  • Fault Tolerance: Difficult to isolate faults. If the main Cable breaks, the entire network goes down.
  • Protocols: Uses CSMA/CD and CSMA/CA to manage data traffic and prevent collisions.

Star Topology

Hub/Switch Central

  • All nodes connect individually to a central device (Hub or Switch).
  • The most popular topology for Modern LAN.
  • Devices are usually configured in a Primary-Secondary relationship.
  • Used for large networks. Requires a central controller or hub.

Ring Topology

Token Passing

  • Data travels in a circle.
  • A "token" is passed around; only the node holding the token can send data.
  • Often used in FDDI (Fiber Distributed Data Interface) networks for high-speed transmission.
  • Flow of data is Uni-directional.
  • Devices usually configured in a Peer-to-peer relationship.

Tree Topology

Star of Stars

  • Known as a "star of stars".
  • It has a root node and connects multiple star networks.

Mesh Topology

Most Robust

  • Every device has a dedicated connection to every other device.
  • If one connection fails, data finds another path. Bi-directional flow is possible.
  • Uses Routers. Highest reliability. Covers Security, robust and eliminating the traffic factor.
  • Devices connected via Point-to-point Link.
  • Drawbacks: Wiring is complex and expensive. Requires routers/switches with many ports. Requires the most amount of wiring.
  • Use Case: Home automation and critical infrastructure where connection failure isn't an option.

Hybrid Topology

  • Mix of two or different topologies.
  • Has 2 or more combinations.

Mobile Ad-hoc Networks (MANET)

  • Type of network where topology changes from time to time.
  • Changes locations and configures itself.
  • Lack of centralized control. Varying network topology. e.g. Bluetooth.

Review & Key Takeaways

  • Flow: Flow of Data in a computer ring network topology is Uni-directional.
  • Terminators: Used in BUS topology.
  • Topology Definition: Physical or logical arrangement of networks is Topology.
  • Central Controller: Star topology requires a central controller or hub.
  • Multipoint: BUS topology requires a multi-point connection.
  • Point-to-Point: Mesh topology has devices connected via Point-to-point Link.
  • Common LAN Topologies: Bus, Ring, Star.
  • Reliability: Mesh topology has the highest reliability.
  • Nodes: Participating computers in a network topology are referred to as Nodes.
  • Tokens: Tokens are involved in a Ring topology. Source computer sends information along with Token. Short message that travels around communication medium is Token.
  • Security: Security and privacy are less in Bus topology. Mesh topology covers Security, robust and eliminating the traffic factor.
  • Bi-directional Links: Mesh topology has bi-directional links between each possible Node.
  • Wiring & Faults: Mesh requires the most amount of wiring. Bus has the toughest fault identification.
  • Acronyms: CSMA/CD (Carrier-Sense Multiple Access with Collision Detection), CSMA/CA (Carrier-Sense Multiple Access with Collision Avoidance), FDDI (Fiber Distributed Data Interface).

Networking Devices

HUB (Physical Layer)

  • Known as Dumb Device.
  • Broadcasts message in network.

Repeater (Physical Layer)

  • Re-generates signals.
  • Considered an Active Hub.

Bridge (Data Link Layer)

  • Connects LANs in which protocols and MAC Address are same.

Router (Network Layer)

  • Connects IP Addresses. Used in WAN & LAN. Connects LANs.
  • Regulates Traffic. Fastest Device.
  • Internetworking device. Data forwards in packets. Uses Routing Table.

Gateway

  • Connects different topologies, protocols.
  • Works on all 7 Layers of OSI Model.

Modem

  • Used in DSL (Digital Subscriber Line).
  • Modulator (Digital to Analog) + Demodulator (Analog to Digital).
  • Used in Telephone lines / dial up connections. Slowest networking device.

Firewall

  • Can be Hardware or Software.
  • Revokes unauthorized access to a computer.

IP Address vs MAC Address

IP Address (Internet Protocol Address)

  • Definition: Identifies device on Internet / Logical Address.
  • Changeability: It can Change (Temporary).
  • Versions: IPv4: 32 Bit/4 Byte (Decimal Notation). IPv6: 128 Bit/16 Byte (Hexadecimal Notation).
  • Layer: OSI Layer 3 (Network Layer).
  • Developer: IPv4 (DARPA), IPv6 (IETF).
  • Command: ipconfig
  • Management: IANA (Global), APNIC (Asia Pacific).

MAC Address (Media Access Control Address)

  • Definition: Address of Networking Device / Physical / Hardware / Burned-in Address.
  • Changeability: Permanent (Can't Change).
  • Size: 48 Bit / 6 Byte (12 digit Hexadecimal Number).
  • Layer: OSI Layer 2 (Data Link Layer).
  • Developer: Xerox PARC.
  • Command: getmac
  • Structure: First 6 hex digits (OUI - Manufacturer), Last 6 hex digits (NIC Specific).
