Please read the following instructions carefully before starting the test:

  1. Total duration of this mock examination is 16 minutes (960 seconds). The countdown timer in the top right corner displays the remaining time. When the timer reaches zero, the examination will submit automatically.
  2. Each question carries +2.0 marks for a correct answer, -0.50 marks (negative marking) for an incorrect answer, and 0 marks for an un-attempted question.
  3. Only one question is displayed on the screen at a time. Selecting an option does NOT automatically jump to the next question or reveal the answer during the test.
  4. Use the Next, Previous, Clear, and Mark for Review & Next buttons at the bottom of the question panel to navigate and manage your responses.
  5. Upon clicking Start Mock Test, the interface will automatically enter Full Screen Mode. You can exit Full Screen at any time using the Exit Fullscreen button in the header.
  6. After submission, your detailed scorecard will be displayed along with step-by-step verified solutions exclusively for Incorrect and Un-attempted questions.
